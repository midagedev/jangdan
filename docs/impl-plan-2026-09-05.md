# 장단 Phase 1 구현 계획 (2026-09-05)

기획서 v2(`docs/plan-2026-09-05-v2.html`) 08절 Phase 1 범위를 코드 단위로 쪼갠 것. 이 문서가
병렬 위임 라운드의 **공통 계약 원본**이다 — 각 라운드 스펙은 여기의 해당 절을 인용한다.
스파이크 게이트(Phase 0)는 5분 언더런 1건만 남기고 전부 통과했으므로 스파이크 코드는 동결하고
(`spike/`는 계측 페이지로만 유지) 제품 코드는 새 위치에 쓴다.

## 1. 아키텍처

```
engine/    순수 Go DSP+시퀀서. TinyGo wasm-unknown → AudioWorklet. 명령(Cmd)으로만 조작.
session/   순수 Go. 이벤트 로그·키프레임·시드 단어·URL 직렬화. 메인 스레드(UI wasm)에서 돈다.
resident/  순수 Go. 오토파일럿: 생성기·에너지 곡선·바이브·포모도로. Cmd를 내놓는다.
cmd/worklet/  TinyGo 진입점(export 표는 §3).  cmd/render/ 네이티브 렌더·해시.  cmd/jdsess/ URL 길이 측정.
app/       Ebitengine(GOOS=js). core/(공용 컨텍스트) view/device/ view/room/ main.go(배선).
app/web/   index.html · host.js(워클릿 호스트·로그·리플레이·텔레메트리) · processor.js · wasm_exec.js
cf/        리포트·텔레메트리 수신 Worker(있음).  tools/  게이트·배포·fal 파이프라인.
```

원칙: **로그가 정본.** 사람 손이든 레지던트든 엔진에 닿는 모든 변경은 `engine.Cmd` 하나로 통일되고,
호스트가 `(블록 인덱스, Cmd, 저자)`로 기록한다. 리플레이·URL 열기·서버 렌더는 전부 "새 엔진 + 같은 로그".
레지던트는 재생하지 않는다(그 출력이 이미 로그에 있다). 엔진은 파라미터를 12비트로 정규화해 저장하므로
로그·키프레임의 uint16이 곧 엔진 값이다(직렬화 왕복에 반올림 오차 0).

## 2. 엔진 계약 (`engine/`) — 리드 소유 파일: engine.go · params.go · cmd.go · state.go · approx.go

### 2.1 파라미터 (`params.go`, 전부 0..1, 엔진이 4095 단계로 양자화)

| ID | 이름 | 매핑 |
|---|---|---|
| 0..7 | BassA: Tune, Cutoff, Reso, EnvMod, Decay, Accent, Wave, Oct | Tune ±12반음(0.5=0) · Cutoff 200Hz..8kHz 지수 · Reso 0..자기발진 직전 · EnvMod 0..4옥타브 · Decay 30ms..2s 지수 · Accent 깊이 · Wave <0.5 톱니 ≥0.5 사각 · Oct 3단(−1/0/+1) |
| 8..15 | BassB: 같은 8개 | 같음 |
| 16..27 | BD·SD·CH·OH·CP·CY 각 Level, Tune | Level 선형 · Tune ±(보이스별 정의) |
| 28 | Delay | 0=꺼짐 · 믹스와 피드백을 한 노브에(믹스 0..0.5, 피드백 0..0.7) · 시간은 템포 동기 점8분 |
| 29 | Drive | 0..1 → 프리게인 1..8, 유리식 소프트클립 |
| 30 | Comp | 사이드체인 깊이 0..1(킥 트리거 → 베이스 게인 덕킹, 릴리즈 120ms) |
| 31 | Master | 0..1 선형, 기본 0.8 |
| 32 | Tempo | 100..160 BPM, 기본 130(=0.5) |

기본값은 `DefaultParams()`가 소유한다(전부 0.5가 아니다 — 표에 있는 기본 참조).

### 2.2 파트·명령 (`cmd.go`)

```go
Part: BassA=0 BassB=1 BD=2 SD=3 CH=4 OH=5 CP=6 CY=7 (NumParts=8)
Cmd{Kind, A, B, C, D uint8; V float32}
  SetParam      A=ParamID              V=값
  BassStep      A=Part(0|1) B=step C=note(0..36, 24=C3 기준 반음) D=flags(bit0 gate, bit1 slide, bit2 accent)
  DrumStep      A=Part(2..7) B=step  D=flags(bit0 on, bit2 accent)
  SelectPattern A=Part(0|1) B=slot(0..7)      — 다음 바 경계에 적용
  Mute          A=Part B=on(0|1)
  Trigger       A=Part(2..7)                  — 패드 즉시 원샷
  Drop                                        — 다음 바 경계에 발동(§2.5)
  ResetPos                                    — 스텝 0·바 0으로(리플레이 시작용)
```
`Apply(Cmd)`는 무할당·클램프(범위 밖은 정규화, 무시하지 않는다: step&15, part 범위 밖은 무동작).

### 2.3 상태 (`state.go`)

`StateSize` 바이트 고정: params[33]u16 · bass 패턴 2파트×8슬롯×16스텝×(note u8, flags u8) · drum 6×16 flags ·
선택 슬롯 2 · 뮤트 비트 1 · 예약. `WriteState(dst) int` / `ReadState(src) bool`(길이·범위 재정규화, 실패 시 false).
보이스 내부 상태(필터 메모리·엔벨로프)는 포함하지 않는다 — 키프레임은 **바 경계의 제어 상태**이고 복원은 바 경계에서만.

### 2.4 시계·신호

`Render(out []float32)`(256 float32, 1블록) 후 읽기: `Block() uint64` · `Step() int` · `Bar() uint32` ·
`Flags() uint32`(직전 블록: bit part=트리거, bit8 바 경계, bit9 드롭 발동, bit10 액센트 트리거) · `Peak() float32`.
`Reset(seed)` — 무할당 재초기화(-gc=leaking에서 `New` 재호출 금지).

### 2.5 DROP

`Drop` 명령은 다음 바 경계에 발동: 전 파트 뮤트 해제, CY 트리거, 8바 동안 `dropEnv` 1→0 선형 감쇠로
두 베이스라인 컷오프 +1옥타브·Drive +0.2를 곱해 준다. 판정·점수 없음. 빌드업은 레지던트가 한다.

### 2.6 보이스 (위임 파일)

- `voice.go`/`filter.go` — 베이스라인: 톱니/사각 오실레이터(PolyBLEP 또는 위상 누산+단순 안티에일리어싱), 다이오드 래더 4폴 근사(레조넌스 루프에 HPF), 앰프·필터 디케이 엔벨로프, 액센트(레벨+엔벨로프 깊이+짧은 디케이), 슬라이드(스텝 길이 동안 지수 포르타멘토), 게이트 오프 시 릴리즈 8ms.
- `drums.go` — BD(브리지드-T 근사: 사인 피치 스윕 + 클릭), SD(톤 2개 + 노이즈 밴드패스), CH/OH(6비트 양자화 금속 노이즈 → HPF, OH는 긴 디케이), CP(노이즈 4연타 + 리버브 꼬리 근사), CY(금속 노이즈 + 밴드 2개, 긴 디케이). Tune은 보이스별 의미(BD 피치, SD 톤, 햇 HPF, CP 밀도, CY 밴드).
- `fx.go` — 드라이브 → 템포 딜레이(점8분, 스테레오 핑퐁, 최대 1초 버퍼 = 48000×2 float32 New에서 할당) → 사이드체인 컴프(BD 트리거 신호 입력) → 마스터 → 소프트클립.

### 2.7 게이트

`go test ./engine/` (결정론·무할당·범위·클램프·상태 왕복) · `bash tools/check-fma.sh` · TinyGo 빌드 import 0 ·
네이티브 300초 SHA-256 == node wasm == 브라우저 OfflineAudioContext(`tools/hash-*.mjs`) · 필터 스윕 스펙트럼 ±3dB/옥타브(참조 앙상블 확보 후 — Phase 1 중반).

## 4. 호스트 프로토콜 (`app/web/processor.js` ↔ `host.js`)

- main→worklet `{t:'cmd', at, k,a,b,c,d,v}` — `at`은 블록 인덱스(0=즉시). 워클릿은 정렬 큐에 넣고 `block ≥ at`인
  첫 블록 시작에 적용. 호스트는 항상 `at = 추정 현재 블록 + 2`로 보내 로그의 블록이 실제 적용 블록과 같게 한다.
- `{t:'reset', seed}` · `{t:'state:set', bytes}` · `{t:'state:get'}` → `{t:'state', bytes, block}`.
- worklet→main `{t:'tick', block, step, bar, flags, peak, ctxTime}` — 4블록마다, flags는 누적 OR. 호스트는
  `ctxTime↔block` 선형 대응으로 `blockNow()`를 추정한다.
- 호스트 API(`window.jd`): `start()`(제스처 뒤) · `cmd(c, author)`(로그 기록 포함) · `state()` · `tick()`(최신 스냅샷)
  · `replay(fromBlock, toBlock)`(키프레임 복원 + 델타 재전송, 3·2·1 뒤) · `log()` · `telemetry(ev, data)`.
- 텔레메트리 이벤트(첫 커밋부터): `first_tap`, `first_sound_ms`, `first_knob_ms`, `exit_60s`, `drop`, `replay_used`,
  `seed_open`, `worklet_error`. `?kind=telemetry`로 기존 Worker에 POST(세션당 1회 배치 + `visibilitychange`에 flush).

## 5. 세션 (`session/`)

- `Entry{Block uint32; Author uint8; Cmd engine.Cmd}` · `Log{Seed uint32; Entries []Entry; Keyframes []Keyframe}` ·
  `Keyframe{Block uint32; State [engine.StateSize]byte}` — 호스트가 16바마다 요청해 넣는다.
- `SeedFromWord(s string) uint32` — NFC·소문자·공백 제거 후 FNV-1a 32. 빈 문자열은 0x9E3779B9.
- `EncodeURL(word, log) string` / `DecodeURL(s) (word, log, error)` — 스텝 경계 양자화, varint+델타, base64url.
  예산: 5분 손 조작 합성 로그(노브 200회 × 중간값 20)가 **2000자 이하**. 초과 시 연속 SetParam 압축(같은 파라미터의
  중간값을 초당 8개로 감량)을 적용하고 실측을 `docs/`에 남긴다.
- `cmd/jdsess`: 합성 로그 생성 → URL 길이 출력(게이트).

## 6. 레지던트 (`resident/`)

- `New(seed uint32, vibe Vibe) *Resident` · `Tick(in Input) []engine.Cmd` — Input{Bar, Step, Now(초), Pomodoro}. 바 경계에서만 결정.
- 생성기: 스케일(마이너 펜타·프리지안·블루스 중 시드 선택) · 밀도 · 휴지·슬라이드·액센트 확률 · 옥타브 점프. 드럼은 킥 골격 + 시드 변주.
- 에너지 곡선: 인트로→빌드→드롭→브레이크다운, 주기 4~8분(시드 파생), 매 주기 시드 파생. 단계별 목표 파라미터 대역과
  드럼 밀도. 노브 이동은 스텝마다 보간(1바에 8회 SetParam까지).
- 바이브: DeepFocus(120, 드럼 얇게, 컷오프 낮게) · Rush(135, 풀 드럼) · Lofi(비트크러시 대신 Drive 낮게+Delay 높게, 느린 템포).
- 포모도로: `Pomodoro{Focus, Rest 분}` 기본 25/5, 첫 세션 5분 데모. 집중 종료 16바 전 빌드, 종료에 Drop, 휴식은 브레이크다운.
- MANUAL 잠금: `Lock(ParamID)` 뒤 그 파라미터는 건드리지 않는다. `Resume()`·포모도로 경계에서 해제.
- `Hand() (param ParamID, active bool)` — 캐릭터 손 애니메이션 타깃(마지막으로 움직인 파라미터, 1바 유지).

발견·결정
- GLM claude-code 하네스는 한 턴 출력 32K 토큰 상한에서 두 번 죽었다(산출물 0) → 런처 기본값 `CLAUDE_CODE_MAX_OUTPUT_TOKENS=64000`, 그래도 파일 분할 쓰기를 스펙에 명시.
- Ebitengine ColorScale은 프리멀티플라이드 색에 곱한다 — 알파만 낮추면 순백이 된다. 알파를 RGB에도 접는다(방·기기 뷰 두 곳에서 같은 사고).
- Kage 셰이더는 `DrawRectShaderOptions.Uniforms`를 바인딩하지 않으면 유니폼이 0으로 채워져 조용히 아무것도 그리지 않는다 → 생성 시점 바인딩으로 구조 봉쇄.
- 캡처 수치 검사(`tools/pixcheck.py`)가 비전 판정의 결함 전부를 숫자로 재현했다 — 이후 렌더 라운드의 완료 조건은 이 수치 게이트다.
