# 이름 결정 — 장단 / Jangdan (2026-09-05)

코드네임 revirth는 ReBirth 상표와 철자 하나 차이라 공개 문구에 쓰지 않는다. 제품명은 **장단(Jangdan)**.

## 왜 장단인가

- 장단(長短)은 국악의 리듬 단위다. 시퀀서·드럼머신 제품에 뜻이 곧바로 닿는다.
- "장단을 맞추다"는 상대 흐름에 따라 함께 놀아 준다는 뜻이다. 비동기 2인 잼과 노동요 오토파일럿의 관계를 한 단어로 설명한다.
- 두 음절, 영어권도 jang-dan으로 읽는다. Wikipedia 표제어도 Jangdan(McCune-Reischauer는 changdan)이라 표기가 흔들리지 않는다.
- 사용자가 먼저 고른 가락은 finger·tune 이중의미가 좋았지만 garak.{com,net,app,dev,io}·GitHub가 전부 점유였고, 가락시장·Star Trek 캐릭터(Elim Garak)와 검색이 겹친다.

## 남은 확인 (Phase 0 첫 주)

1. **KIPRIS 상표 검색**: `장단`, `JANGDAN` — 9류(소프트웨어)·41류(엔터테인먼트·음악 서비스)·42류. 이 세션에서는 kipris 포털이 연결 거부라 미확인.
2. USPTO·EUIPO에서 JANGDAN 검색(일반명사라 등록 가능성은 낮게 보되, 선등록 유무만 확인).
3. X 핸들 `@jangdan`·`@jangdanfm` 수동 확인.
4. jangdan.fm 등록(.fm은 연 US$100 안팎). .app/.dev/.io는 방어 등록 선택.
5. 일반명사이므로 상표는 로고 결합 또는 `Jangdan FM` 형태로 출원 검토.
